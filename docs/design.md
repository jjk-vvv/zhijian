# 纸间：设计与实施计划

用户授权自由选题；目标为仅前端、至少三个页面、十五个 Vue 单文件组件，覆盖官方互动教程，代码易读，并尽可能提供公网链接。

## 设计

以阅读生活为主题。相比只展示内容的旅行页，阅读主题能自然容纳筛选、收藏、阅读进度与表单；相比电商，无需模拟付款或服务器。选用 Vue 3 Composition API、Vue Router 和 Vite，不引入后端或庞大的 UI 依赖。

三个路由：`/` 发现好书（主题筛选、搜索、排序、详情与收藏），`/shelf` 我的书架（阅读状态、阅读进度、移出书架），`/notes` 阅读手记（创建、预览、编辑、检索、删除）。未知路径提供返回首页的页面。所有展示内容与本地用户数据分离。

视觉：独立书店杂志风。纸白、深森林绿、柔和灰绿；中文宋体用于展示标题，系统中文黑体用于操作文字。首页使用生成的阅读静物图，书籍使用自制的概念封面，并非特定出版版本。桌面四列书籍，手机两列；导航在手机保持可用。弹窗支持 Escape、焦点循环、关闭后恢复焦点；减少动态效果设置受尊重。

## 架构与边界

- `views/` 负责页面级筛选状态、布局与组合。
- `components/` 按布局、书籍、书架、手记、通用交互分组；props 输入、emits 输出，组件不直接读写 localStorage。
- `composables/useLibrary.js` 提供共享响应式数据与收藏、进度、手记操作，深度 watch 保存，readonly 暴露数据。
- `utils/storage.js` 负责读取、校验与持久化；损坏数据可恢复，存储失败保留当次会话并显示提示。
- `data/books.js` 为固定精选书目，推荐语为本站原创介绍；不显示虚构评分或声称真实社群数据。

## 错误与边界

空搜索、空书架、空手记显示明确的后续操作。手记标题与正文必填且限制长度；移出和删除需确认。加载后根据白名单清洗本地数据、限制进度范围。首次访问提供标明来源的示例书架与手记。路由更新标题，导航成功后聚焦主内容。无账号，无支付，无远程数据同步。

## 实施顺序

1. 创建 Vite 工程、路由、静态书目和本地状态层。
2. 完成通用组件与品牌布局，再完成发现页。
3. 完成书架与手记页，使用户操作贯通。
4. 用单元测试验证存储边界；用浏览器测试三页、收藏、进度、手记增删改和刷新持久化；检查桌面与手机。
5. 生产构建，编写 README 与教程知识点对照，打包源码和 dist。
6. 尝试通过 Sites 发布公开网站；同时保留 Netlify 配置与拖拽上传用静态压缩包。如外部服务失败，明确报告状态。

## 验收

至少 3 个独立可导航页面；至少 15 个有明确职责且被实际使用的 SFC；教程 1–14 步逐项有代码落点；生产构建与功能测试通过；源码包不包含 node_modules、凭证或个人浏览器数据。
